# Система бронирования билетов в кинотеатр

React-приложение для онлайн-бронирования билетов в кинотеатре с административной панелью управления.

## 🚀 Функционал

### Для пользователей:
- Просмотр расписания сеансов
- Выбор даты и зала
- Выбор мест в кинозале
- Бронирование билетов
- Получение электронного билета с QR-кодом

### Для администратора:
- Управление кинозалами (создание, редактирование, удаление)
- Управление фильмами
- Управление расписанием сеансов (Drag-and-Drop интерфейс)
- Настройка цен на билеты
- Включение/отключение продаж билетов

## 🛠 Технологии

- **Frontend:** React 18, React Router DOM 6
- **UI Framework:** React Bootstrap 2, Bootstrap 5
- **API:** Axios для работы с backend
- **Drag-and-Drop:** React DnD
- **QR-коды:** qrcode.react
- **Даты:** date-fns
- **Стили:** CSS3, Bootstrap
